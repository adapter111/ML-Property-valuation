# ML-Property-valuation

# California Housing Price Prediction using PyTorch

A deep learning project implementing a custom Multi-Layer Perceptron (MLP) from scratch using **PyTorch** to predict median house values based on the classical California Housing dataset.

---

## 🚀 Project Overview

While traditional machine learning libraries like Scikit-Learn provide quick baseline models (e.g., Linear Regression, Random Forest), this project dives into the fundamentals of **Deep Learning**. 

Key concepts demonstrated in this repository:
* **Custom PyTorch `Dataset` and `DataLoader`** for efficient batching and shuffling.
* **Data Preprocessing & Standardization** using Scikit-Learn and PyTorch tensors.
* **Neural Network Architecture Design** using `torch.nn` (Fully Connected layers with non-linear `ReLU` activations).
* **Manual Training Loop** implementation (`forward pass`, `loss calculation`, `backward pass` / backpropagation, and `optimizer step`).
* **Model Evaluation** using regression metrics (RMSE, MAE, $R^2$ Score).

---

## 🛠️ Tech Stack

* **Language:** Python 3.14.10
* **Deep Learning Framework:** PyTorch
* **Data Manipulation & Metrics:** NumPy, Scikit-Learn
